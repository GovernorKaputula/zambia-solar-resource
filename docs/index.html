03 / Research record

The assumptions stay
with the result.

Working code, source snapshots, and independent result checks make the study inspectable.

A

Respect availability.

Non-calendar features end at t−8. POWER reports a 5–7 day solar-data lag. Historical release vintages were unavailable, so this remains a retrospective benchmark with a stated availability assumption.

B

Know the measurement.

GHI is solar irradiation on a horizontal surface. It comes from satellite-informed models at grid scale. Agreement with this source is not ground-sensor validation or measured electricity output.

C

Leave an audit trail.

Six cached source responses retain exact request URLs and SHA-256 digests. Automated tests check time boundaries, interval construction, saved metrics, and explorer values. SQL independently reconciles errors and coverage.
